# ☕ Café Aroma

Projeto de portfólio desenvolvido para uma cafeteria fictícia.

## Objetivo

Criar um site institucional responsivo, acessível e com navegação simples, priorizando a experiência do usuário.

## Páginas

- Home
- Sobre nós
- Cardápio
- Nossas lojas
- Blog
- Contato
- Página 404

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Foco em UX

O projeto prioriza:

- arquitetura da informação;
- hierarquia visual;
- navegação intuitiva;
- responsividade;
- acessibilidade básica;
- destaque para o cardápio e principais ações.

## Observação

Este projeto não utiliza logotipos externas. Os logotipos foram construídos com CSS e emojis como placeholders. Posteriormente, as áreas visuais podem receber imagens reais.

## Como executar

Abra o arquivo `index.html` em um navegador ou utilize o Live Server no VS Code.

Projeto fictício criado para fins de portfólio.
